运行环境 & 体验路径

环境要求：Python 3.8+ / Ollama / deepseek-r1:1.5b（或其他轻量模型）

设备要求：无 GPU 要求，4GB 以上内存即可运行

安装方式：git clone https://github.com/k3234/lumiagent

启动命令：pip install requests && python agent_core.py

离线可用：完全本地运行，无需联网

没有独立显卡？没关系。LumiAgent 就是为你的设备设计的。只需安装 Ollama 并拉取一个轻量模型，93 行 Python 代码即可启动你的本地 AI 编程助手。
